# レンズの実験室

凸レンズ・凹レンズ・レンズなしと、組み合わせレンズの光線を比較する日本語Webアプリです。薄いレンズの近軸モデルで計算します。

## 起動

`index.html` をブラウザで開いて使用できます。インストール・ビルド・インターネット接続は不要です。`index.html`、`style.css`、`optics.js`、`app.js` を同じフォルダに置いてください。

ローカルサーバーを使う場合：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8765/ を開きます。

## 操作

- キャンバスの余白をマウスまたは1本指でドラッグすると、図全体をパンできます。ろうそく・レンズ・F・観測者の目の上では、それぞれの位置や焦点距離を変更します。
- マウスホイール、トラックパッドのピンチ、iPadの2本指ピンチで、指やポインターの位置を中心に50〜400%までズームできます。2本指を同じ方向へ動かすとパンします。2本指操作中はろうそく・レンズ・F・観測者の目を移動しません。
- キャンバス左下の「−」「＋」でもズームできます。「表示を戻す」はズームとパンのみを初期表示に戻し、レンズの配置や表示設定を保持します。
- ろうそくを左右にドラッグして位置を変更します。
- 観測者の目を上下左右にドラッグすると、見え方の像の大きさ・位置・レンズの開口を通して見える範囲が連動します。目は最後のレンズより10 cm右側から x=240 cmまで、高さは −100〜100 cmで移動できます。図の外へ移動した目は、余白のドラッグや縮小で探せます。
- レンズ本体をドラッグして位置を変更します。選択中のレンズを濃い輪郭で示します。
- 選択中のレンズの左右にある **F** をドラッグして焦点距離の大きさを10〜50 cmで変更します。左右のFは連動します。数値入力と2Fの表示はありません。
- ヘッダーの「凸レンズ」「凹レンズ」は選択中のレンズに適用します。「レンズなし」は配置を保持したまま全レンズを外し、凸・凹への切り替えで配置を復元します。
- 「＋ レンズ追加」で選択中と同じ種類・焦点距離のレンズを空いた位置へ追加します（最大4枚）。追加したレンズを選択して種類を変え、凸・凹を組み合わせられます。「選択レンズを削除」で枚数を減らせます。
- レンズはろうそくと観測者の間で移動します。レンズ同士の間隔は最低8 cmで、ドラッグ中の順序は保ちます。
- ヘッダーの「光線」「距離」「数式」「見え方」で表示を切り替えます。数式と見え方は初期状態で非表示です。見え方はキャンバス右上、数式は左上のオーバーレイで、光線図の幅を狭めません。
- 距離表示は選択中のレンズの a・b・|f| とレンズ間隔 d を示します。数式も選択中のレンズについての式です。
- ろうそく、レンズ、FはTabで選択し、左右矢印で操作できます。目は上下矢印でも操作できます。Shift併用で10 cm移動します。「表示を戻す」では目の位置も保持し、「リセット」で初期位置へ戻します。
- 「リセット」でレンズ1枚・初期位置・初期表示に戻ります。ズームとパンも初期表示に戻ります。

## 計算と表示

光軸の右向きを正、上向きを正とし、観測者の初期位置は (x, y)=(140, 0) cm、ろうそくの初期位置は x=−60 cmです。ろうそくの高さは30 cm（以前の18 cmから延長）、炎の大きさも拡大しています。描画した炎の先端と計算上の光源の高さを一致させています。レンズの半口径は50 cmです。

光線を `(高さ y, 傾き u)` で表し、距離 d の伝播では `y ← y + d*u`、レンズでは `u ← u − y/f` として、左から右へ順に追跡します。口径を外れる作図光線はその位置で止めます。実像・虚像の位置は光線伝達から求めます。

組み合わせレンズの a は前のレンズによる中間像からの物体距離です。中間像が次のレンズより右にある場合は a が負の虚物体になり、平行光の場合は a=∞ になります。各レンズで `1/a + 1/b = 1/f`、その段の倍率 `m = −b/a` が成立します。最終像の高さは全段を通した倍率で描画します。中間像が無限遠でも、次のレンズの像を計算できます。

見え方は全レンズを通って現在の目の位置へ入る光線の角度から求めた模式図です。ろうそくの根元と先端の光線を別々に求めることで、目の上下移動による像のずれと倍率を区別します。目から各レンズへ逆向きに光線を追い、ずれた円形開口の共通部分で像を切り取ります。最終実像が観測者の位置またはその先にあるときは、大きなろうそくにぼかしを適用します。このぼけ量と拡大率は眼球の厳密な光学計算ではありません。投影には視角の正接を使い、大きな像は縮めずに表示枠で切り取ります。先端の光が口径を外れても全体を消さず、各レンズの円形開口を通して見える部分を残します。無限遠でも有限の視角をもつ像は描画します。光線図上の最終像は理想近軸像の位置であり、明るさは再現しません。

背景には光軸上の消失点へ集まる遠近グリッドを表示します。等間隔の奥行きを投影した格子は遠方ほど密になり、破線の補助枠は像（レンズなしでは物体）までの距離に応じて拡大・縮小します。これらは奥行きを示すガイドで、実際にレンズ越しに見える背景ではありません。

回折、収差、厚み、目の調節範囲は扱いません。大きな角度や近距離は定性的な学習用です。

## 検証

```sh
node --test tests/optics.test.cjs
```

21件の自動テストで、単レンズ、凸・凹レンズ、2〜3枚のレンズ、中間虚物体、中間像・最終像の無限遠、光線の連続性、口径、観測条件、目の移動による投影と開口の変化を確認します。

ブラウザの操作検証は `tests/navigation.browser.js` をPlaywright CLIの `run-code --filename` で実行します。ローカルサーバーを起動して次のように開きます（Playwright CLI・ブラウザ導入済みの環境）。

```sh
playwright-cli -s=lens-navigation open http://127.0.0.1:8765 --browser msedge
playwright-cli -s=lens-navigation run-code --filename tests/navigation.browser.js
playwright-cli -s=lens-navigation run-code --filename tests/observer.browser.js
```

28項目で、ホイールの中心座標、パン、ズーム後の物体操作、表示のみのリセット、倍率制限、1本指／2本指操作、指の追加・解除・キャンセル、複数レンズ、縦横サイズ変更、狭い画面、表示切替を確認します。スクリーンショットは `output/playwright/` に保存します。タブレットの検証はChromium系ブラウザのタッチエミュレーションです。iPad実機のSafariと公開環境は未確認です。

観測者の検証では、マウス・タッチの上下左右ドラッグ、ズーム後の座標、キーボード、実像を横切ったときのぼけ、移動範囲、2本指への切り替え、拡大した見え方パネルの画面内配置を確認します。パネルは通常画面で最大270 px、狭い画面では150 px幅です。高さの小さい横画面では、見え方の画像と見出しを横並びにして目への重なりを抑えます。

操作構成の参考：[Javalab「凸レンズと凹レンズ」](https://javalab.org/ja/lens_ja/)。コードと図は本アプリ用に作成しています。
